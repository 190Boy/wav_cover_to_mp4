# 封面圖 + WAV 批次轉 MP4 網頁版

這是一個純 HTML 網頁工具，可以指定一張封面圖片，搭配多個 WAV 音檔，批次輸出成 MP4 影片。

## 使用方式

1. 解壓縮 ZIP。
2. 開啟 `index.html`。
3. 選擇一張封面圖片。
4. 選擇多個 WAV 音檔。
5. 按下「開始轉換」。
6. 每個 MP4 轉完後，頁面下方會出現下載連結。

## 輸出規格

- 影片尺寸會依照封面圖原始尺寸輸出。
- 例如封面是 `2560 × 1440`，輸出的 MP4 也是 `2560 × 1440`。
- 如果封面寬或高是奇數，工具會自動調整為偶數，避免 H.264 MP4 編碼失敗。
- 音訊會轉為 AAC。

## 注意事項

- 第一次使用需要網路，因為網頁會下載 FFmpeg WebAssembly 核心。
- 轉換都在瀏覽器本機執行，圖片與音檔不會上傳到伺服器。
- 如果直接雙擊 `index.html` 無法使用，請改用 VS Code 的 Live Server 開啟。
- 一次轉換約 10 首左右較適合。
- 音檔太長或封面解析度太高時，瀏覽器轉檔會比較慢。

## 建議使用情境

適合少量批次轉換，例如：

- 一張歌曲封面搭配多首 WAV
- 每首歌各自輸出一個 MP4
- 不想安裝 FFmpeg 或額外軟體

如果一次要轉大量音檔，或每首歌都很長，仍建議使用本機 `ffmpeg.exe` 批次檔版本。
